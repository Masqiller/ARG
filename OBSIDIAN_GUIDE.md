# 🌌 Obsidian Brain Launcher Guide

This guide explains how to launch and navigate the **Autonomous Vibe Engine (ARG)** Knowledge Graph.

## 🚀 1. Launch the Application
If Obsidian is not currently open, run the following command in your terminal from the `Fusion` directory:

```bash
cd /home/smit/Downloads/Fusion
./Obsidian.AppImage --no-sandbox &
```

## 📂 2. Open the Vault
1. Once Obsidian opens, click **"Open folder as vault"**.
2. Navigate to and select this exact directory:
   `/home/smit/Downloads/Fusion/awwesome-ruflo-graphify/graphify-out/obsidian`

## 🕸️ 3. View the Knowledge Graph
1. Once the vault is open, look at the file list on the left.
2. Open the **`README.md`** file.
3. Click on the **`[[AWWESOME_SKILL_TREE]]`** link to see the master index.
4. To see the visual graph, press **`Ctrl + G`** on your keyboard.

## 🛠️ Troubleshooting (Graph not visible?)
- If the graph looks empty, check the **Filters** menu in the Graph View and ensure "Files" and "Tags" are enabled.
- Ensure you have selected the `obsidian` folder inside `graphify-out`, not just the root folder.
